# 健身教練 Lite

靜態精簡版：按部位教練提示、健身房／家用動作教學、21 日短片式圖解挑戰、本機訓練記錄。

**預覽：** https://lingling3899.github.io/fitness-coach-lite/?v=20261028f

## 功能

1. **部位教學** — 胸、背、肩、手臂、腿、核心：短提示、目標肌群、推薦動作。
2. **儀器／動作** — 健身房器械同家用徒手／啞鈴各精簡數款；步驟、常見錯誤、新手組數×次數、安全提示；詳情含錯誤／正確示意。
3. **短片教學** — 21 日挑戰卡網格（DAY 徽章、原創簡化解剖 SVG 肌群高亮、動作名）；詳情含 ✕／✓ 姿勢對比、肌群＋組數列。**而家內建 18 款解剖圖解示意短片**（`pushup`／`bw-squat`／`plank`／`lat-pulldown`／`pec-deck`／`glute-bridge`／`db-row`／`db-shoulder-press`／`db-curl`／`leg-press`／`smith-squat`／`lunge`／`seated-row`／`face-pull`／`triceps-pushdown`／`smith-bench`／`shoulder-press-machine`／`dumbbell-press-home`，非真人）；其餘可自備連結（本機 `fitnessCoachLite.videos.v1`）。
4. **訓練記錄** — 只存瀏覽器 `localStorage`（鍵：`fitnessCoachLite.logs.v1`）；日期、組數、次數、可選重量、備註；可篩選／刪除。
5. **說明** — 免責：示意非醫療，請咨詢專業教練。

## 本機

開 `index.html`，或任何靜態伺服器。唔使 build、唔使登入。

## 注意

非醫療建議、非真人教練替代。傷病或特殊狀況請先咨詢專業人士。解剖圖為簡化示意。
