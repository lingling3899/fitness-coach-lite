# 健身教練 Lite

靜態精簡版：輸入想增肌部位即時建議儀器／動作、每日小 tips、按部位教練提示、健身房／家用動作教學、圖解目錄（全部海報＋21 日挑戰）、本機註冊／登入同個人訓練記錄。

**預覽：** https://lingling3899.github.io/fitness-coach-lite/?v=20261028i

## 功能

1. **目標搜尋** — 輸入或撳胸／背／肩／手臂／腿／核心／臀／全身，即時分「健身房儀器」同「家用／徒手／啞鈴」建議。
2. **今日小 tips** — 熱身、呼吸、溫柔進階、恢復等短提示（示意，非醫療）；亦可睇各部位教練 tip。
3. **部位教學** — 胸、背、肩、手臂、腿、臀、核心：短提示、目標肌群、推薦動作。
4. **儀器／動作** — 健身房器械同家用徒手／啞鈴各精簡數款；步驟、常見錯誤、新手組數×次數、安全提示；詳情含錯誤／正確示意。
5. **圖解目錄** — 全部 18 款解剖海報上下滑（2–3 欄金邊卡）；撳卡即入教學同短片。可切「全部圖解／21 日挑戰」同「健身房／家用」。詳情含 ✕／✓ 姿勢對比、肌群＋組數列。**內建 18 款解剖圖解示意短片**（非真人）；其餘可自備連結（本機 `fitnessCoachLite.videos.v1`）。
6. **註冊／登入** — 本機多帳戶（`fitnessCoachLite.users.v1` + `fitnessCoachLite.session.v1`）；密碼以 salt＋SHA-256 雜湊，唔存明文。
7. **訓練記錄** — 登入後每人自己一套日誌（`fitnessCoachLite.logs.v1.<用戶名>`）；日期、組數、次數、可選重量、備註；可篩選／刪除。資料只在此裝置瀏覽器，唔上雲。
8. **說明** — 免責：示意非醫療，請咨詢專業教練。

## 本機

開 `index.html`，或任何靜態伺服器。唔使 build。訓練記錄要先本機註冊／登入（唔上雲）。

GitHub Pages：`main` 分支、根目錄。已放 `.nojekyll`。
