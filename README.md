# 健身教練 Lite

靜態精簡版：輸入想增肌部位即時建議儀器／動作、每日小 tips、按部位教練提示、全身肌肉圖（女圖／男圖可切）、健身房／有氧／普拉提／家用動作教學、圖解目錄、減脂增肌粗估＋營養餐示例、本機註冊／登入同個人訓練／目標記錄。

**預覽：** https://lingling3899.github.io/fitness-coach-lite/?v=20261029g

## 功能

1. **目標搜尋** — 輸入或撳胸／背／肩／手臂／腿／核心／臀／有氧／普拉提／全身；「女士」「女士普拉提」可命中普拉提類。
2. **女士 · 普拉提** — 首頁明顯 CTA、圖解目錄「普拉提 · 女士」chip（女士常選）；一撳篩選地墊／拉根。
3. **女圖／男圖／通用** — 頂欄切換（`fitnessCoachLite.prefs.v1`）；肌肉圖 8 角女體／男體；普拉提 11 款女體海報；其他動作無女圖時顯示通用圖並註明。
4. **今日小 tips** — 熱身、呼吸、溫柔進階、恢復等短提示（示意，非醫療）。
5. **部位教學** — 胸、背、肩、手臂、腿、臀、核心、有氧。
6. **肌肉圖** — 可拖曳旋轉解剖全身圖（8 角度）；熱點橙色高亮；簡介、一般飲食靈感（非醫療）同相關動作。
7. **儀器／動作** — 健身房、有氧、普拉提地墊／拉根、家用；步驟、錯誤、組數參考。
8. **圖解目錄** — 全部解剖海報；可切全部／21 日同健身房／有氧／普拉提／家用。內建解剖示意短片（非真人）。
9. **目標／營養** — Mifflin-St Jeor 粗估 BMR／TDEE；減脂／增肌／維持熱量範圍＋粵語營養餐示例；可儲存／刪除快照（`fitnessCoachLite.goals.v1.<用戶名或 guest>`）。非醫療、唔保證減重增肌。
10. **註冊／登入** — 本機多帳戶（`fitnessCoachLite.users.v1` + `fitnessCoachLite.session.v1`）。
11. **訓練記錄** — 登入後個人日誌（`fitnessCoachLite.logs.v1.<用戶名>`）；可篩選／刪除。
12. **說明** — 免責：示意非醫療，請咨詢專業教練／營養師。

## 本機

開 `index.html`，或任何靜態伺服器。唔使 build。訓練記錄要先本機註冊／登入（唔上雲）。

非醫療建議、非真人教練替代。傷病、懷孕或特殊狀況請先咨詢專業人士。解剖圖為簡化示意。營養餐只係一般飲食靈感。
